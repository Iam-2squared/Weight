# Weight

無料・端末内処理の筋トレアプリ。V1 はカメラで腕立て伏せを自動カウントする Push-up Counter です。

## 機能

- MediaPipe Pose Landmarker で正面から見える左右の肩・肘・手首を認識
- 肩と手の位置関係、肘の曲げ伸ばしから「上 → 下 → 上」を1回としてカウント。腰・膝・足首の映り込みは不要
- 肩幅で動きを正規化し、撮影距離に合わせて上側の基準位置を自動調整
- 静止中の揺れ・手だけの動き・追跡の見失いによる誤カウントを軽減
- カメラのリアルタイムプレビュー、骨格表示、肘角度、状態表示
- 音声カウント、一時停止／再開、カメラ切替、リセット
- KGS 11th（KGS01）の出席番号・4桁PINでログイン可能。ゲストでのカメラ利用も可能
- Weight独自のデータベース・有料APIなし

## ローカルで動かす

Node.js 22.12 以降を使用してください。

1. npm install
2. npm run dev
3. http://localhost:5173/ にアクセス

検証コマンド: npm run typecheck、npm test、npm run build。

カメラは HTTPS または localhost でのみ使用可能です。初回のAIモデルとWASMの取得にはインターネット接続が必要です。

## KGS 11th アカウント連携

- 既存のKGS出席番号と4桁PINを利用します。新しいKGSアカウントを作成したり、PINをWeightに保存したりしません。
- 入力したPINはWeightサーバーからKGSの専用サーバー間APIにのみ送ります。ブラウザへKGS統合秘密鍵・KGSトークンを返しません。
- Weight側には独立したホスト専用`Secure; HttpOnly; SameSite=Lax` Cookieを設定し、KGS側で失効を検証します。
- WeightはKGSのメンバーID・表示名だけ表示します。クラスの予定・投稿・写真・成績・ウォレットへのアクセスは実装しません。
- Vercel環境変数（サーバーのみ）`KGS_WEIGHT_API_ORIGIN`（KGS共有版の固定HTTPS origin）、`KGS_WEIGHT_INTEGRATION_SECRET`（KGS側と共有する**専用ランダム秘密**）を設定します。両方ともブラウザに公開しません。
- 連携環境変数未設定・KGS障害時はログインを拒否しますが、腕立てカメラをゲストで利用できます。
- 自動でトレーニング履歴をKGSへ同期しません。


## デイリー・チャレンジ・ランキング・設定（V1 UI）

画面下のナビゲーションは左から **デイリー（カレンダー）／チャレンジ／ランキング／設定** の4アイコンです。iPhoneホーム画面追加時も下端のセーフエリアを確保します。

- デイリー：日本時間の日付で実施日を集計し、連続日数・最長連続日数・総回数をカレンダーに表示。
- チャレンジ：専用の計測画面へ移動し、カメラ起動・自動カウント・一時停止・音声・終了保存を操作。
- ランキング：**総合回数／連続回数**を切り替え、KGS 11thのログインメンバーの順位・ユーザー名・回数を一覧で表示。
- 設定：KGS 11thログイン、音声、端末の記録削除。
- 記録：カウントが1回以上の計測を終了した時だけローカルストレージへ保存。ゲストとKGSメンバーは別の保存領域に隔離。動画や関節位置は保存しません。

共有ランキングはKGS専用のサーバー認証APIと`kgs.weight_ranks`の集計値で表示します。未認証ユーザーに他人の記録は渡しません。動画や本人の詳細履歴はKGSへ送信しません。架空の順位やサンプルデータを実記録として表示しません。

## 記録とランキング

- **最高連続**: AIがカウントした1回から次の1回まで10秒以内（ちょうど10.000秒を含む）であれば継続。10秒を超えて次のカウントがなければ、現在の連続が終了し、次の1回から再スタート。過去の最高連続回数は保持します。
- **総合回数**: 端末に保存されたすべての完了セッションの腕立て総数です。カメラの計測画面は従来どおりトータルの回数だけを表示します。
- **チャレンジ**: 最高連続・総合回数を表示（前回・1セッションの最多回数表示から変更）。
- **ランキング**: 「総合回数」と「連続回数」の2タブで、選んだ記録の多い順に順位・ユーザー名・回数を表示します。「連続回数」は保存済みの最高連続記録を使い、現在の計測中の連続数ではありません。同数はメンバーID順で安定して並べます。高さ・積み上げの演出は使いません。
- **軽量化**: ランキングの背景画像・人物の積み上げ・二方向のスクロール画面を読み込まず、一覧だけ表示します。カメラの姿勢認識ライブラリは測定開始時のみ読み込みます。
- **既存の保存データ**: 以前の回数は総合回数にそのまま加算します。10秒の判定を記録していなかったセッションについては、連続回数を推測して追加しません。
- **共有ランキング**: Push UPにKGS 11thアカウントでログインしたユーザーは**自動的に**共有ランキングに登録されます。「参加する」操作は不要で、回数が0でも表示します。KGSログインユーザー間で表示名・総合回数・最高連続回数を比較し、ゲストや未認証ユーザーには他人の記録を返しません。どちらも既存の共有APIに保存済みの記録を使います。
- **プライバシー**: KGS連携認証を持たないゲストは、自分のローカル記録だけ表示します。ログイン時と記録更新時に集計値を自動同期します。設定の「記録を削除」は**この端末の履歴のみ**を削除し、サーバーの累積ランキング記録は消しません。サーバーへの同期失敗時はエラーを表示します。
- **サーバーへの保存**: KGSの非公開schema `kgs.weight_ranks` にPush UPへログインしたユーザーごとに集計1行のみ保存し、RLS ON・公開ロール権限なし。動画・関節情報・PIN・各回の記録は送信しません。メンバー認証は従来のKGS Weight連携API経由。

## 撮影と判定

スマホを横向きにして体の正面、床の近くに固定し、左右の肩、肘、手首が画面に入るように撮影します。腰や足が画面外でも計測します。初期カメラは自分を確認できるフロントカメラで、背面カメラにも切り替えられます。縦向きのスマホでは黄色い「横向き！」の案内を表示し、横向きにすると隠れます。スマホを回す案内であり、正面からの認識方式はそのままです。縦向きでも開始や計測をブロックしません。

腕を伸ばした上側の姿勢を基準として、肩が手の位置へ下がり、上側に戻る一連の動きを数えます。肩幅で距離を正規化し、肘の曲げ伸ばしも合わせて確認します。横から撮る方式の固定した肘角度や、腰と足首を結ぶ姿勢判定は使用しません。静止中の揺れを数えないよう平滑化・複数フレームの安定・クールダウンを使います。一時停止や長い追跡中断の後は、新しい一連の動作が必要です。カメラ画面には次の動作を表示し、ライブ映像の再生時刻に依存せず判定を更新します。

**精度の制約:** 肩・肘・手首が隠れる、逆光、素早い動き、服装や撮影位置などで誤判定し得ます。上半身の動きだけを使うため、全身のフォームや胸と床の実距離は判定しません。これは運動回数の目安であり、医療・運動指導の代替ではありません。

## データ・プライバシー・課金

映像の推論はブラウザ端末内で行い、Weight独自のサーバーにはカメラ映像を送信しません。WASMはjsDelivr、学習済みモデルはGoogle Storageから取得します。MediaPipeは性能や利用状況のメトリクスをGoogleに送る場合があります。詳細は MediaPipe のプライバシー通知（https://www.npmjs.com/package/@mediapipe/tasks-vision）を参照してください。

Vercel Hobby（利用条件内）、React、Vite、MediaPipeを利用し、有料API・有料サーバーを導入しません。将来の利用規約や無料枠の変更には留意します。明示承認なしに有料サービスを追加しません。

## リリース判定

CI／単体テストの成功と、実機の認識精度は別です。iPhone Safari／Android Chrome実機でカメラ許可・音声・発熱・10回の腕立ての認識精度を検証するまで V1 は実機確認待ちです。
